Data explorer

Every message from every device, stored in one table. Any device and any application, with no per-application tables.

Table schema: device_data (one row per message)

Devices report on the data points their device profile declares. Those keys go into the values JSON column, so adding a new device type or application never changes this table. Applications read from it through aggregations (delta, average, time in state) over time windows.

idMessage id (device + timestamp)
tsTime the device took the reading (timestamptz; partition/hypertable key)
tenant_idOwning tenant; every query is scoped by it
device_idSending device
asset_idAsset the device was linked to at ingest time (nullable)
profile_idDevice profile, which gives the meaning of each key in values
valuesJSONB, e.g. {"part_count": 15320, "run_status": "running"}
